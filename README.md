# 🏛️ CLUSTER: 뉴스·소셜 토픽 추출 및 입법예고 연계를 통한 입법수요지수 산출 모델

CLUSTER는 방대한 규모의 비정형 뉴스 및 소셜 데이터를 분석하여 실시간 사회적 담론을 추출하고, 이를 실제 국회 입법예고 데이터와 연계하여 **입법수요지수(LDI)** 를 정량적으로 산출·제공하는 의사결정 지원 플랫폼 프로젝트입니다.

## 🎯 프로젝트 목적 및 목표

- **여론과 제도의 간극 해소**: 뉴스·SNS 대규모 비정형 텍스트를 의미 기반 토픽(Semantic Embedding)으로 정규화하여 실시간 사회적 수요 파악
- **실증적 연계 분석**: 추출된 토픽과 입법예고 데이터를 의미적 유사도 및 시간 축(Temporal Window) 기준으로 매칭하여 여론의 법제화 과정 추적
- **입법수요지수(LDI) 개발**: 토픽의 화제성·집중도·응집성·확산성을 통합한 단일 지수 산출
- **실행형 서비스 구현**: Flask 웹 기반 대시보드로 정책 담당자의 조기 경보 활용 지원

## 📚 데이터 및 분석 방법론

### 활용 데이터
- 뉴스·소셜 데이터: 약 **26만 건** (빅카인즈, X, 네이버 블로그, 인스타그램, 유튜브 등)
- 입법예고 데이터: 국회 입법예고 시스템 (개인정보보호법, 정보통신망법, 자본시장법, 아동복지법 4개 법률군)

### AI 파이프라인 (5단계)
### 담당 역할 — 데이터 수집·전처리·토픽 모델링

- MinHash LSH 활용 자카드 유사도(0.9 이상) 기반 근사 중복 문서 제거
- KoNLPy 형태소 추출 및 채널별 불용어 처리
- KR-SBERT 문장 임베딩 → UMAP 차원축소 → HDBSCAN 군집화
- BERTopic + c-TF-IDF 토픽 추출 (coherence score > 0.8)
- 코사인 유사도(임계값 0.6) + 180일 시계열 창 기반 입법예고 매칭

### LDI 산식
- **Buzz (화제성)**: total_posts, max_zscore, ewma_slope
- **Focus (중심성)**: entropy, rep_kw_count, uniq_words
- **Depth (응집성)**: avg_tok_len, avg_len, sent_ratio
- **Spread (확산성)**: source_entropy_norm, speed_intensity
- **Penalty (지속성 페널티)**: days_to_peak

## 📊 주요 분석 결과

- 표본 297개 토픽 (연계 44개, 14.8%)
- **감성 비율(sent_ratio)**: Spearman 0.877 — 입법 전이에 가장 강한 신호
- **민감군** (자본시장·아동복지): 텍스트 내재적 지표 반응 우수, 예측 용이
- **둔감군** (개인정보·정통): 소셜 확산·출처 다양성 지표 보정 필요
- Flask + KoBART 요약 + PyVis 키워드 네트워크 대시보드 구현

## ⚠️ 한계점

- 180일 시계열 창·유사도 임계값 0.6 기준으로 지연된 입법 경로 일부 누락 가능
- 분석 범위가 4개 법률군으로 한정되어 일반화에 제약
- 플랫폼 편향성·전처리 손실·감성 사전 도메인 불일치 등 측정 오차 잔존
- 결과는 인과관계가 아닌 관측 상관관계 및 예측 가능성의 실증으로 해석해야 함
